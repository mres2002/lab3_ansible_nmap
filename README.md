Ansible Lab П05 — Работа с переменными и сканирование NMAP
📝 Описание
Данный репозиторий содержит Ansible playbook для автоматизации сканирования портов с помощью NMAP.

🎯 Цель работы
Научиться работать с переменными в Ansible
Освоить копирование файлов на удаленные хосты
Научиться запускать команды и собирать результаты
Использовать циклы и функции поиска
📁 Структура репозитория
ansible_nmap_lab/ ├── nmap_scan.yml # Основной плейбук ├── targets.txt # Список целей для сканирования ├── inventory.ini # Файл инвентаризации с хостами ├── README.md # Документация └── screenshots/ # Скриншоты выполнения

🚀 Использование
Требования
Установленный Ansible на управляющей машине
Целевые хосты с доступом по SSH
Права sudo на целевых хостах
Установка NMAP на управляющей машине
# Для Ubuntu/Debian
sudo apt update
sudo apt install ansible

# Для CentOS/RHEL
sudo yum install ansible
